Animações (Fragmentos)

Você pode fazer o conteúdo aparecer em partes.

  • Primeiro ponto (Aperte a seta)
  • Segundo ponto, ideal para suspense!
  • Como fazer? Adicione class="fragment" na tag (como num <li> ou <p>).
Também funciona para blocos inteiros!

Códigos Fonte

Professores da área de TI vão adorar o Highlight de sintaxe nativo:


def calcular_media(notas):
    """Calcula a média de uma lista de notas"""
    
    total = sum(notas)
    media = total / len(notas)
    return media

Você pode até destacar linhas específicas usando data-line-numbers="1-2|4-6".
